## Submission Process

### Step 1: Prepare Build
```bash
# Build release APK/AAB
./gradlew bundleRelease

# OR for APK (older method):
./gradlew assembleRelease

# Verify signing
jarsigner -verify -verbose -certs app-release.aab

# Check size is reasonable
# AAB should be < 100 MB
# Individual APKs should be < 150 MB
```

### Step 2: Upload to Google Play Console
```
1. Navigate to Google Play Console
2. Select "Arriendo Fácil" app
3. Go to "Testing" → "Internal Testing"
4. Create new internal testing release
5. Upload .aab (App Bundle) file
6. Wait for signing and verification (usually instant)
7. Review build details
8. Create release on Internal Testing track first
```

### Step 3: Internal Testing Phase (Optional)
```
Duration: 1-2 days
Steps:
1. Invite 5-10 internal testers
2. Distribute testing checklist
3. Gather feedback and screenshots
4. Fix any issues
5. Prepare for production
```

### Approval vs Rejection

**If Approved** ✅:
1. App appears in Play Store search
2. Available for download worldwide
3. Users can leave reviews
4. Monitor reviews and crash reports
5. Plan update schedule

**If Rejected** 🔴:
1. Email from Google Play explaining reason
2. Common reasons:
   - Missing privacy policy
   - Misleading app description
   - Policy violation
   - Test account not provided
   - Security concerns
3. Fix issues and resubmit (< 1 day typically)
