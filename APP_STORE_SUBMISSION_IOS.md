### Rejection Scenarios & Solutions

**Scenario 1**: "Requires test account credentials"
```
Solution:
- Create demo@arriendo-facil.com account
- Add sample property
- Add demo tenant
- Pre-generate an invoice
- Provide credentials in App Review Notes
```

**Scenario 2**: "Encryption declaration incomplete"
```
Solution:
- Ensure all encryption methods documented
- Check "Standard Encryption" exemption
- Upload detailed response
- Resubmit
```

**Scenario 3**: "Rate limiting causes rejection"
```
This is unlikely. Explain in notes:
- Rate limiting is for server protection
- Does not affect normal user experience
- User can retry after short delay
- Standard industry practice
```
